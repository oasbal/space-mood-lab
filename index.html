어떤 공간을 꾸며볼까요?
인테리어의 시작은 공간을 이해하는 것입니다. 같은 가구, 같은 색상이라도 원룸에 놓느냐, 넓은 거실에 놓느냐에 따라 느낌이 완전히 달라져요. 먼저, AI가 변환할 빈 방을 하나 골라주세요.
이 공간의 스타일은?
스타일은 공간의 정체성입니다. 하나의 키워드가 벽의 재질, 가구의 형태, 색감까지 모두 결정합니다. 마음에 드는 스타일을 하나 골라보세요.
디자이너 Tip
실제 인테리어 프로젝트에서도 가장 먼저 결정하는 것이 스타일입니다. 클라이언트가 "따뜻한 느낌"이라고 말하면, 디자이너는 "북유럽? 와비사비? 보헤미안?" 중 어디에 가까운지 파악하죠.
어떤 기분이 드는 공간을 원하나요?
같은 "미니멀" 방이라도 따뜻한 미니멀과 차분한 미니멀은 다릅니다. 무드는 공간에 들어갔을 때 느끼는 감정이에요.
분위기 연출 예시
따뜻한 → 카페 라떼 색 소파 + 무릎 담요 + 간접 조명
드라마틱 → 어두운 벽 + 스포트 조명 하나 + 금속 소재
몽환적 → 쉬어 커튼 + 라벤더 빛 + 구름 같은 러그
차분한 → 화이트 + 우드 + 아무 소리 없는 고요함
빛은 어떻게 들어올까요?
조명은 공간의 분위기를 70% 결정합니다. 똑같은 방도 자연광이 가득하면 상쾌하고, 간접조명만 켜면 아늑하죠.
조명의 비밀
인스타에서 "분위기 좋다"고 느끼는 카페 사진, 대부분 골든아워(해질녘)에 찍은 거예요.
어떤 재료와 색감이 좋을까요?
소재는 공간의 촉감, 색상은 공간의 온도입니다. 소재 하나, 색상 하나를 각각 골라주세요.
조합의 마법
"노출 콘크리트 + 딥 네이비" → 도시적이고 쿨한 느낌. "원목(오크) + 웜 화이트" → 따뜻하고 자연스러운 느낌.
공간을 채울 것들을 골라볼까요?
빈 방에 가구 하나가 들어가면 비로소 "공간"이 됩니다. 핵심 가구 하나, 악세서리 하나를 골라보세요.
인테리어 디자이너처럼
프로 디자이너도 모든 것을 한꺼번에 넣지 않습니다. "이 공간의 주인공"이 될 가구를 먼저 정하고, 나머지를 거기에 맞추죠.
나의 공간 레시피가 완성되었어요!
지금까지 고른 키워드들이 합쳐져 하나의 공간 디자인 지시문이 되었습니다. 이걸 그대로 Opal 앱에 붙여넣기하면, AI가 여러분의 아이디어를 실제 이미지로 만들어줍니다.

미션 브리핑
팀원과 함께 클라이언트의 요청을 꼼꼼히 읽어보세요. 좋은 디자인은 클라이언트의 말 속에 숨은 진짜 니즈를 파악하는 것에서 시작합니다.
팀 활동
팀원과 소리 내어 읽고, "이 사람이 진짜 원하는 건 뭘까?" 이야기해 보세요.
클라이언트 분석
좋은 디자이너는 바로 스타일을 고르지 않습니다. 먼저 "왜?"를 물어요. 팀원과 아래 질문에 대해 이야기하고, 핵심을 적어보세요.
디자인 컨셉 도출
분석을 바탕으로 공간의 방향성을 정합니다. 팀원과 합의하여 이 공간을 한마디로 표현해보고, 핵심 키워드 2~3개를 골라주세요.
디자인 결정
컨셉에 맞춰 구체적인 요소를 선택합니다. 미션의 필수 조건에 맞는 항목이 표시됩니다. 나머지는 팀이 자유롭게 결정하세요.
프롬프트 완성
모든 선택이 조합되어 AI에게 전달할 공간 디자인 지시문이 완성되었습니다. Opal 앱에 이 내용을 넣으면 AI가 이미지를 생성합니다.
발표 준비
실제 디자이너는 결과물을 클라이언트에게 "왜 이렇게 디자인했는지" 설명합니다. 아래 질문에 팀의 답을 적어보세요. 이것이 여러분의 발표 스크립트가 됩니다.
